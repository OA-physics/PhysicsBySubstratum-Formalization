# Formal verification of *Consequences of Strict Background Independence*

This directory documents the Lean formalization accompanying the manuscript
*Consequences of Strict Background Independence*.

The formal Lean development is located in:

`SBILeanProject/SBI/`

The manuscript-level Lean entry point is:

`SBILeanProject/SBI.lean`

The SBI formalization provides the verified structural foundation imported
by later manuscript formalizations, including *The Structure of Time*.

Detailed proof-path and traceability documentation is currently available
in the repository-level SBI documentation files. These will be organized
under this directory without changing the underlying formal development.
