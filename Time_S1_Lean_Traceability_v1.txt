Time — S1 to Lean Traceability Registry
=========================================

Purpose
-------
For every important Definition, Lemma, Proposition, Theorem, Remark, and
Corollary in S1, identify one Lean declaration (or a small public interface)
that serves as its manuscript-facing formal counterpart.

The registry also records a small number of unnumbered semantic bridges whose
meaning is used by the numbered proof.  These are kept explicit so that a
semantic encoding choice cannot be mistaken for a new physical axiom or for a
derived theorem.

A manuscript-facing interface should be recognizable beside the corresponding
S1 statement.  Implementation helpers may sit below the interface declaration,
but the manuscript statement should not have to be reconstructed from unrelated
Lean internals.

File field
----------
The file field gives the project source file in which the principal interface
is defined, independent of temporary local filename suffixes.

Status convention
-----------------
MATCH     = manuscript statement and Lean interface have been checked and agree.
ENCODING  = explicit semantic or representational choice; deductive use is
            checked, while adequacy of the interpretation remains conceptual.
SCOPE     = deliberate manuscript statement outside the present Lean theorem
            layer; the boundary itself has been checked for consistency.
CHECK     = plausible interface identified, but detailed comparison remains open.
GAP       = no adequate manuscript-facing Lean interface identified.
TODO      = interface identified, but dependency-report or manuscript cleanup
            remains open.
