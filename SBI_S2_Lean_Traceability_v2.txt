SBI — S2 to Lean Traceability Registry
========================================

Purpose
-------
For every important Definition, Lemma, Proposition, and Theorem in S2,
identify one Lean declaration that serves as its manuscript-facing interface.

A manuscript-facing interface should be a Lean declaration whose statement
or type can be placed beside the corresponding S2 statement and recognized
as formalizing essentially the same mathematical claim.

File field
----------
For each manuscript-facing Lean interface, record the project source file in
which the declaration is defined.  This is the logical project filename
(e.g. NetworkObjects.lean), independent of temporary version suffixes used
during review.

Status convention
-----------------
MATCH  = manuscript statement and Lean interface have been checked and agree.
CHECK  = plausible interface identified, but statement/type correspondence
         still requires detailed comparison.
GAP    = no adequate manuscript-facing Lean interface currently identified.
TODO   = interface identified, but dependency-report or manuscript cleanup is
         still required.

The purpose of this registry is semantic traceability, not merely name
matching.  Helper declarations may sit below the interface declaration, but
the manuscript statement should not have to be reconstructed from unrelated
Lean implementation details.
